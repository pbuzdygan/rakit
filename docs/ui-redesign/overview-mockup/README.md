# Overview — operations dashboard mockup

Otwórz `index.html` bezpośrednio w przeglądarce. Mockup nie wymaga buildu ani połączenia z backendem.

Widok proponuje:

- jeden zwarty pasek najważniejszych liczb zamiast osobnych dużych kart,
- tabelę stanu usług i integracji,
- filtrowaną kolejkę spraw wymagających reakcji,
- czytelną tabelę pojemności szaf,
- ostatnie operacje powiązane z konkretnymi zasobami.

Można zwijać menu, przełączać jasny/ciemny motyw, odświeżać dane, filtrować kolejkę oraz klikać elementy robocze.
