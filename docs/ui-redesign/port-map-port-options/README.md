# Port Map — warianty prezentacji portów

Otwórz [`index.html`](index.html) bezpośrednio w przeglądarce. Mockup nie wymaga buildu ani zależności zewnętrznych.

Można w nim:

- przełączać cztery warianty prezentacji portów,
- porównywać urządzenia 8-, 16-, 24- i 48-portowe,
- sprawdzić układ 16-portowy 8×2 oraz 48-portowy 24×2,
- klikać połączone porty i obserwować wyróżnienie drugiego końca,
- wybierać połączenia z tabeli i filtrować jej zawartość.

Wariant A zachowuje największą zgodność z fizycznym panelem i jest propozycją bazową. Wariant B optymalizuje czytelność przez banki po osiem portów. Wariant C utrzymuje zwarty przegląd urządzeń, a szczegóły pokazuje w powiększonym pasku `Port focus`. Wariant D odtwarza zweryfikowaną skalę poprzedniego Rakit: porty o wysokości 42 px i minimalnej szerokości 34 px, połączone z nowym nagłówkiem urządzenia.
